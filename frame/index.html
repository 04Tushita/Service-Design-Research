Synthesizing qualitative user evidence into targeted design challenges, human-centered points of view, and generative opportunity spaces.

Persona Deep-Dive
Archetype Persona Wireframe

The Overwhelmed Service Coordinator

Responsible for multi-stakeholder service alignment. Pressured by client expectations and paralyzed by non-transparent departmental review queues.

  • Goal: Zero-latency handoffs and automated milestone visibility.
  • Friction: Manual email status chasing across disconnected silos.
Core User Story

As an operational coordinator...

"I want a centralized, real-time dashboard tracking intake milestones and assigned review owners,

So that I can proactively identify departmental bottlenecks before client deadlines are compromised and avoid manual email check-ins."

User Story Narrative Illustration
Point of View (POV) Formulation

User + Need + Insight

User: Mid-level institutional service coordinators
Need: A transparent, self-validating intake handoff mechanism
Insight: Because silence from internal gatekeepers produces acute anxiety and forces defensive manual spreadsheet duplication that consumes over 35% of their working week.

Generative How Might We (HMW) Questions

Translating user tensions into creative springboards for system design.

HMW 01 • Visibility

Demystify Review Queues

How might we provide immediate, automated visibility into queue status so coordinators never need to send a manual status check?

HMW 02 • Autonomy

Front-load Verification

How might we enable users to self-validate submission dependencies upfront before sending the dossier to internal audit teams?

HMW 03 • Handoffs

Eliminate Diffusion of Duty

How might we establish clear singular accountability for inter-departmental transfers with automated escalation timers?
