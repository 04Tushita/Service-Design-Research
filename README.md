# Service Design Research Presentation

An interactive, live presentation website for showcasing Service Design Research.

## Overview
This repository contains the source code, visual assets, interactive wireframes, and design artifacts for the Service Design Research project.

## Project Structure
- `index.html`: Main presentation landing page
- `css/`: Custom styling and design system
- `js/`: Interactive presentation logic and micro-interactions
- `assets/`: Wireframes, diagrams, and media
